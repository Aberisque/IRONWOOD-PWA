How do I get a server address?

Run the included Crimson Command Node.js server on an existing computer or a trusted host. Place it behind HTTPS with private access, then enter its URL above. A locally running backend on this phone can use http://127.0.0.1:8787.

Do not open the development server directly to the public Internet.
